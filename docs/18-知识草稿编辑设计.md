# 知识草稿原位编辑设计

手工知识草稿支持创建人继续编辑。只有 `DRAFT` 状态且当前账号为创建人的知识可修改；请求必须携带当前 `currentVersionNumber` 对应的强 `If-Match`，服务端同时校验当前版本 ID 和版本号，冲突返回 409，不覆盖其他页面已经保存的内容。

保存不会改写原版本：服务端保存一条新 `DRAFT` 版本，将上一草稿版本标记为 `SUPERSEDED`，再原子切换知识的当前版本。标题、分类、标签、服务目录和正文重新执行与创建相同的长度、格式、发布目录及组织边界校验。正文仍是受控纯文本，历史正文只对草稿所有者或授权审核人员可见。

前端“我的草稿”提供编辑动作，打开时重新读取服务端草稿和正文；保存成功后使用响应中的新版本号，409 时保留用户输入并提示重新加载比较。
