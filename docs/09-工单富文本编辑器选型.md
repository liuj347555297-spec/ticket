# 工单富文本编辑器选型

## 结论

工单“问题现象 / 服务说明”采用 **TipTap 3 + ProseMirror**，并以服务端受控 HTML 白名单作为存储与展示边界。建单页保留 Element Plus 标准表单和默认结构化说明模板；浏览器生成的 HTML 必须经服务端清洗后才能持久化或在详情页渲染。

TipTap 是随前端制品一同交付的开源 JavaScript 编辑器库，**不需要联网、不调用云端 API，也不需要采购其服务**。在内网环境中，将依赖包锁定并打入前端构建产物即可运行。协同编辑、AI 辅助、云端存储等均不是一期工单编辑器的依赖；若后续确有多人实时编辑需求，应另行在内网部署协同服务并完成安全评审。

## 对比

| 方案 | 许可证 / 当前版本核验 | Vue 3 与扩展性 | 结论 |
| --- | --- | --- | --- |
| TipTap 3 | MIT；`@tiptap/vue-3` 3.30.3 | Vue 3 原生封装，ProseMirror 文档模型，支持自定义节点、受控粘贴、附件卡片、历史版本和后续协同 | 推荐 |
| Quill 2 | BSD-3-Clause；2.0.3 | 成熟且轻量，但复杂业务节点、严格 schema 与可控扩展弱于 ProseMirror | 备选 |
| wangEditor 5 | MIT；核心 5.1.23 | 中文使用体验较好，但 `@wangeditor/editor-for-vue` 当前 1.0.2 的对等依赖为 Vue 2 | 不作为 Vue 3 基线 |
| CKEditor 5 | 双许可证 | 功能强，但许可、构建与高级协同能力的产品边界更复杂 | 不优先 |

版本与许可证于 2026-08-25 通过 npm 元数据核验；上线时仍应锁定版本并纳入依赖漏洞扫描。

## 上线前安全契约

1. 客户端仅提交受限 HTML；不得提交任意脚本、样式、URL 协议或事件属性。
2. 服务端使用 HTML 白名单再次清洗，拒绝脚本、内联事件、`style`、`iframe`、`data:` 和非受管附件 URL；纯文本提取用于检索、案例匹配与敏感词检查。
3. 正文、纯文本摘要、编辑器版本和清洗策略版本分开保存；工单历史保留正文快照，不能被后续人员编辑覆盖。
4. Vue 仅对已服务端清洗且带内容类型标记的正文使用 `v-html`；其他内容保持文本插值。富文本附件必须走既有附件隔离、扫描和授权下载链路。
5. 富文本的粘贴、图片、表格、链接、@提及与代码块按白名单逐项开放；当前开放段落、列表、加粗、斜体、代码块、HTTP/HTTPS 链接、12/14/16/18 四档字号，以及受管 PNG/JPEG 图片。

## 内网离线交付要求

1. 在具备审批的构建环境下载并锁定 npm 依赖；内网生产环境只部署构建后的静态前端资源，不执行在线安装。
2. 将 npm 缓存或私有制品仓库纳入离线软件包管理，保留依赖版本、许可证与漏洞扫描报告。
3. 编辑器禁用远程图片、远程字体、外部链接预览、遥测和云端协同插件；图片仅允许上传至平台受管附件服务。
4. CSP 保持 `connect-src 'self'`（以及经审批的内网接口）；不得为编辑器放开外网域名。

## 当前页面规则

- “已发布表单版本”说明改为标签后的帮助提示，减少页面噪声。
- “问题现象 / 服务说明”按工单类型预填默认结构模板；用户可通过 TipTap 进行受限格式化。
- 服务目录、动态下拉、日期和多选字段采用 Element Plus 表单控件，保持标准化布局与键盘可用性。
- 图片先作为工单附件上传至隔离区，扫描通过后才在说明末尾写入受鉴权的内联附件地址；不接受 Base64、外网 URL 或任意图片 URL。
- 当前工具栏不开放表格、嵌入、远程资源或协同编辑。

## 表单配置边界

1. 申请人、申请组织、IAM 用户 ID、工单编号、流程实例、状态、处理人和审计信息属于**系统字段**：由 IAM 或服务端生成，只读展示，不能通过表单配置改为可填写字段。
2. 服务目录下的业务字段属于**版本化表单字段**：应在后台配置为文本、长文本、单选、多选、日期/时间、布尔、受控标签、配置项引用或受控富文本；字段的必填、长度、字典、帮助文字、顺序、脱敏与是否参与案例匹配均随已发布版本固化。
3. 当前“问题现象 / 服务说明”是受控的核心富文本系统字段，所有目录均可使用。动态富文本字段在后台配置接口完成前不开放，避免未经服务端清洗的 HTML 被写入 `structuredFields`。
4. 表单配置须采用“草稿 → 校验 → 审批 → 发布 → 版本冻结 → 回滚/停用”流程；已产生工单始终按提交时的表单版本和身份快照展示，不能受人员调岗或后续表单修改影响。
