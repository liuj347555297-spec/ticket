# 开发安全门禁

适用范围：Vue 3 前端、Spring Boot 单体、Flowable、构建镜像与所有交付脚本。门禁应在内网 CI 中运行；任何例外必须由安全负责人书面批准、标注责任人和失效日期。

## 1. 版本与供应链

| 控制项 | 强制要求 | 发布判定 |
|---|---|---|
| 版本冻结 | Maven 使用 parent/BOM 与 Maven Wrapper；前端使用 `package-lock.json` 或 `pnpm-lock.yaml` 并执行 lockfile-only 安装；容器镜像使用不可变 digest。 | 锁文件、Wrapper 或镜像 digest 缺失即失败。 |
| 依赖来源 | Maven/npm 只允许访问内网制品库；依赖代理、来源和校验和可追溯。禁止构建时从公网临时下载。 | 发现未授权仓库或动态版本（`LATEST`、`RELEASE`、范围版本）即失败。 |
| SBOM | 每次构建生成 CycloneDX 或 SPDX SBOM，覆盖 Maven、npm、容器/基础镜像与操作系统包；与制品、构建号、Git 提交关联保存。 | 没有 SBOM 不得进入制品库。 |
| CVE / 许可证 | 扫描直接与传递依赖、镜像和 OS 包；严重/高危漏洞默认阻断，中危须风险例外，低危纳入修复计划。仅使用通过法务许可清单的许可证。 | 严重/高危未豁免即失败；豁免到期自动恢复阻断。 |
| 补丁治理 | 升级经测试、SBOM 重生成与 CVE 复扫；离线补丁须记录来源、哈希、审批、影响和回滚方案。 | 无变更记录或复扫结果不得发布。 |

## 2. 密钥、配置与构建

- 代码、测试夹具、构建日志、前端打包产物不得含密码、访问令牌、私钥、Cookie、真实个人信息或生产连接串；提交、合并请求和发布前均执行 secret 扫描。
- 密钥只从受管密钥服务或部署环境注入，采用最小权限和可轮换标识；禁止将 `.env`、证书私钥或明文 `application-prod.yml` 提交 Git。
- CI 采用最小权限短期凭据，构建环境隔离；构建脚本不得以管理员/root 身份运行，不执行未经固定版本约束的远程脚本。
- 产物必须可复现并带构建号、Git commit、SBOM 和签名/哈希；部署只接收来自受信任制品库的已扫描产物。

## 3. 越权与接口安全（必须由后端执行）

1. **默认拒绝。** 每个业务接口、服务方法和异步消费者同时校验：当前身份状态、RBAC、组织/服务/队列/CI 数据范围、工单关系以及当前状态/流程任务。
2. **对象级授权。** 工单详情、列表、评论、附件、导出、审批、告警关联、知识正文和报表均逐对象验证；不得只依赖菜单、按钮、前端路由或列表过滤。禁止相信请求中的用户 ID、组织 ID、角色、队列、优先级、状态或处理人。
3. **流程与协同动作。** Flowable 任务 ID、流程节点编码、目标 IAM 用户 ID 均不代表授权。提交、分类、分派、受理、处理中、待反馈、解决、关闭、重开、撤销、挂起、恢复、升级、转办、协办、抢单、主办指定、交接班、会签、内部评论必须逐次校验：对象关系、角色/数据范围、当前状态、流程实例归属、已发布 BPMN 定义版本/节点、任务候选人/受让人/委派关系、工单与任务双乐观锁版本、动作字段白名单和审批策略。目标状态、流程变量、审批结论、SLA 时间、优先级、队列、处理人、候选人名单、会签阈值和授权范围不得信任客户端传入值。
4. **候选人、抢单与会签。** 候选资格由已发布 BPMN/服务目录规则和当前 IAM 投影实时计算，不能通过用户搜索结果、任务 ID、缓存或客户端传入的候选人 ID 获得。抢单须以任务受让条件和双版本原子比较更新，成功者唯一；释放、委派、转办和交接班须验证班次、技能、队列、数据范围、职责分离和当前处理关系。会签使用服务端控制的 BPMN 多实例/会签策略，参与人数、通过阈值、完成条件及未完成任务处置不可由请求体修改；参与人增减、会签完成和超时均记录独立审计事件。
5. **受控跳转。** 只能创建审批申请，不能通过 API 直接移动流程实例；服务端验证来源任务归属、节点白名单、硬审批/授权节点保护、双人审批、任务处置和 SLA 影响。申请、审批、执行、拒绝均产生不可篡改审计事件，且审计员与平台管理员均不得修改或删除。
6. **防重放与幂等。** 每个工单、任务、协同、评论和跳转写操作必须同时验证会话 CSRF、一次业务意图的 `Idempotency-Key`、认证主体、操作类型、目标工单/任务及规范化请求指纹；相同绑定仅返回第一次结果，键复用但内容/主体/目标不一致必须冲突。幂等记录在保留期内防重放、在过期后按受控策略拒绝或重新申请，且与流程/审计事务原子关联；禁止只按 UUID 或仅在前端去重。
7. **会话。** 使用 OIDC 授权码 + PKCE（启用 SSO 时）和服务端 `HttpOnly`、`Secure`、`SameSite` Cookie；访问令牌不得放在 localStorage。所有写接口验证 CSRF 令牌，CORS 仅允许明确的内网门户源站。
8. **输入与输出。** 使用 Bean Validation、允许列表、参数化查询、分页上限和统一错误模型；富文本服务端净化并配置 CSP，禁止内联脚本。文件隔离存储、随机对象键、扫描后放行、下载再次对象鉴权。
9. **审计。** 对登录、授权拒绝、配置、导出、附件下载、流程和集成调用记录请求 ID、主体、对象、结果、来源和前后摘要；日志不得记录密码、令牌、Cookie、完整敏感附件或堆栈。审计事件须使用追加写、时间戳、事件序号/关联 ID、前序哈希或等效防篡改链，并将操作时的 IAM 身份快照与授权判定摘要一并固化；业务事务提交失败不得留下伪成功审计，成功动作不得缺失审计。
10. **IAM 只读投影与同步。** 平台仅保存 IAM 用户、组织、岗位及其映射角色/数据范围的只读投影：不保存密码、不创建本地认证账号、不通过平台编辑或停用 IAM 用户/组织。同步只允许使用受管连接器、固定字段映射和服务端保存的增量游标；触发请求、导入文件或消息不得携带 IAM 地址、密钥、令牌、任意脚本或未验证的字段映射。全量同步须受维护窗口、频率、容量和单飞/幂等锁控制；增量/全量任务均记录申请人身份快照、来源版本摘要、记录计数、结果、拒绝原因码和不可篡改审计关联。
11. **同步导入与个人信息最小化。** 若 IAM 采用文件或批量导入作为受控备选，仅接受管理员预登记的来源、格式、签名/校验和、大小和字段白名单；先在隔离区做结构、编码、重复 ID、组织环路和越权字段校验，再由服务端事务化合并。原始文件、失败行和完整联系方式不得通过 API、应用日志、工单评论或普通审计详情返回；按数据保留期加密留存或安全清理。用户/组织查询按数据范围、用途和最小字段集返回，并限流、防枚举。
12. **历史身份一致性。** 工单提交、分派、审批、协作、评论、消息和审计事件保存 IAM 用户 ID 与当时的姓名、组织、岗位、角色摘要、投影版本和时间快照。调岗、改名、停用或组织重组不得回写历史快照；当前 IAM 投影仅用于新的授权与候选人计算。
13. **服务目录与动态表单。** 运行时只允许读取当前主体可见的已发布目录/表单版本；创建工单、预匹配和字典联动均由服务端按该版本重新校验。动态 `structuredFields` 只可包含已发布字段编码，未知、隐藏、只读、类型不符、无效字典值、无效联动值以及超限字段必须拒绝，不得“兼容保留”。字段定义仅支持受控字段类型、长度/范围、内置格式规则和声明式条件；禁止 HTML、JavaScript、模板表达式、正则注入、SQL、任意 URL/回调、动态组件、任意流程变量和前端规则代码。敏感字段默认不参与案例匹配，接口/日志/错误信息按字段脱敏策略最小化返回。
14. **字典与标签治理。** 字典和标准标签的维护按服务/组织数据范围逐对象授权、乐观锁、审批发布和不可篡改审计；已被发布表单或历史工单引用的编码不得静默删除、复用或改变语义。字典条目必须校验唯一编码、层级环、适用范围、大小和发布状态；运行时仅返回字段声明且当前主体有权使用的有效值。标签统一 Unicode 规范化、去重、长度/数量限制、保留词和控制字符检查，按纯文本输出编码；禁止以标签、字典名称、说明或帮助文本注入 HTML/XSS、链接、脚本、路由、权限或数据范围。自由标签只能作为受限业务检索输入，不能创建标准标签或影响自动路由。
15. **目录管理与发布。** 目录、动态表单、字典、标准标签和规则均先生成草稿，发布必须冻结版本、校验引用完整性、走双人复核/审批（申请人与审批人不得为同一主体）并记录身份快照、变更前后摘要、数据范围、审批与审计关联。平台管理员不因角色自动跨越业务管理范围；审计员只读且不能写配置。发布版本不可原地修改，回滚只能选择已审计的历史发布版本并再次审批；运行中请求不得使用草稿或未审批缓存。
16. **规则案例匹配。** 建单前匹配仅使用已发布、版本受控的确定性规则：目录、CI、允许的结构化字段、标准标签、错误码和规范化关键词。当前禁止 AI、向量检索、语音、外部模型调用、自动处置、自动建单、自动关闭和客户端提交/修改规则表达式、分数、案例可见性或路由结果。规则输入先按动态表单和数据范围校验、限流、脱敏；规则输出仅可返回当前主体有权查看的脱敏知识/已解决案例摘要，不得泄露工单、内部评论、附件、处理人、规则实现、其他组织服务或敏感字段。规则配置来源、版本、命中与建议展示必须审计，且规则变更与业务配置一样受控发布。
17. **消息收件人、站内信与外部 IM。** 消息事件创建时，收件人只能由服务端从当前工单关系、已发布流程候选人/受让人、受控订阅规则或有效 IAM 只读投影计算；客户端请求、前端路由、评论、标签、模板变量和回调不得携带或覆盖 IAM 用户/组织、手机号、邮箱、WPS/企业微信标识、群聊、Webhook 或任意地址。投递前再次验证当前 IAM 状态、消息可见性、服务/组织范围和通知偏好；离职、停用、调岗后失去资格的主体不得收到新通知，历史事件身份快照只用于审计追溯。站内信按“消息—收件人”单独保存已读状态，读取、标记已读和投递状态查询均逐对象校验当前收件人，防止以消息 ID、分页或搜索枚举他人消息。
18. **事务性 outbox、重试与重放控制。** 工单/流程/审批业务提交、消息创建、收件人快照、审计事件和 outbox 投递意图必须在同一数据库事务中原子落库；业务失败不得投递，成功业务不得静默丢失消息。每条投递使用服务端生成的唯一键（至少绑定业务事件、收件人身份快照、通道、模板发布版本和消息类型），数据库唯一约束与消费者租约/锁共同保证至少一次消费下的有效一次投递；客户端永不提交投递键、尝试次数、状态或重试时间。消费者使用固定指数退避、最大尝试次数、可恢复租约、死信/最终失败状态和告警；网络超时、进程重启、重复消费或供应商重复回执不得产生重复业务消息、重复审计或无限重试。原始 outbox 载荷加密/最小化存放，仅消费者可读；普通 API 仅返回脱敏状态，不提供手工重放或任意重投接口。
19. **WPS IM、企业微信及后续通道适配。** 外部 IM 只能经服务端允许列表中的适配器调用，适配器统一实现身份解析、固定模板渲染、速率限制、投递幂等、超时、回执归一化和审计。WPS IM、企业微信及后续适配器的租户配置、应用凭据、签名私钥、回调验证材料、代理/端点和 IAM 映射均仅以部署环境或密钥服务的受管引用注入：业务数据库、OpenAPI 响应、审计详情、异常、指标标签、前端构建产物和日志均不得保存或输出明文值、可定位密钥的路径、完整供应商 ID、收件人 ID 或原始回执。外部请求只允许固定 HTTPS/内网允许地址、证书校验、固定超时和出站网络最小放行；禁止按模板、标签、工单字段或管理员请求动态指定 URL、协议、请求头、方法或反序列化类型。通道状态接口仅报告脱敏健康和受管密钥引用可用性。
20. **模板与内容安全。** 消息模板、模板变量定义和通道策略只能以草稿—双人复核—冻结发布版本受控维护；申请人与审批人职责分离，发布/回滚均审计。模板采用变量允许列表和类型/长度限制，渲染后执行纯文本编码或受限富文本净化；禁止表达式执行、脚本、HTML 事件、任意链接、动态 URL、SSRF 参数、模板 include、反射、循环/递归和从工单原文透传敏感字段。消息内容遵从来源工单、评论、附件和字段的可见性/脱敏策略；对外 IM 默认不发送内部评论、附件正文、令牌、密码、完整联系方式或无权对象信息。
21. **受控通道测试与审计。** 测试投递仅 `PLATFORM_ADMIN` 可发起，且仅能向服务端解析的当前管理员本人或预登记测试组发送固定、无业务数据的纯文本模板；不得指定收件人、模板正文、变量、端点或任意渠道参数。测试请求须 CSRF、频率限制、幂等键与请求指纹绑定，并通过 outbox 异步执行；返回“已排队”不代表投递成功。消息创建、收件人计算依据、投递尝试/结果、抑制、重试、最终失败、通道配置状态变更和受控测试均写入追加式审计链，记录身份快照、授权摘要、通道、脱敏原因码、关联业务事件和请求 ID；不得记录明文内容、密钥、令牌、完整外部 ID 或原始供应商回执。
22. **组织→通道路由与聚合。** 路由规则只把服务端可信来源的“收件人当前 IAM 组织 + 平台产生事件”映射到受控通道，绝不能选择、扩大、替换或暴露收件人。规则字段仅限 IAM 组织 ID、是否匹配下级、已发布事件、受控 `channelCode`、`IN_APP` fallback、通道优先级、去重/聚合窗口和启用状态；禁止任何用户/群组/手机号/外部 IM ID、地址、端点、模板正文/变量、表达式、脚本、密钥和客户端事件。服务端在固定窗口内仅按可信的收件人、来源对象、事件、已发布路由/模板版本和最终通道做去重/聚合，不能因为同名标题、客户端键或跨工单数据合并；强制待办绝不因聚合而遗漏。规则仅以草稿—双人复核—冻结发布方式生效，申请人与审批人职责分离；发布时拒绝组织范围越权、未发布事件/通道、优先级歧义及不安全 fallback。每条 `notification_delivery` 与 outbox 投递意图均持久化命中的已发布规则版本或默认/fallback 路由快照（组织匹配、事件、请求/最终通道、fallback 决策、聚合窗口、时间），后续规则、组织或通道变更不得改写历史。
23. **WPS 企业应用卡片跳转。** WPS IM 的真实投递目标是企业应用通知卡片，卡片跳转回工单平台；适配器受管配置明确 `appId`、允许的 API `endpoint`、仅运行时可解析的 `secretRef`、受信任 `platformBaseUrl` 和已发布 `templateRef`，但这些配置不作为普通 API 响应、日志或审计详情输出。卡片 `targetUrl` 仅由服务端以受信任 `platformBaseUrl` 加允许的内部资源相对路径生成，须绑定当前已授权资源且不包含 token、会话、密码、SSO code、任意 query 密钥、开放重定向或客户端提供的 URL。认证前只允许平台签名/会话绑定的内部恢复路径，认证成功后仅恢复该允许路径，绝不接受 `returnUrl`、`redirectUrl`、Referer、卡片正文或任意 query 作为跳转依据。点击卡片必须回到平台认证边界：启用 SSO 时遵守既定 SSO；SSO 未启用时仍走平台正常认证与对象级授权，外部卡片不是登录凭据或越权通行证。
24. **用户偏好与强制待办。** 用户只能查看和调整当前 IAM 主体自己的、已受管启用通道中的可选消息类别偏好；偏好不保存或修改外部地址、组织、收件人、端点、模板或路由。服务端计算最终 `effectiveEnabled`：通道不可用/无受控外部映射可安全回退 `IN_APP`，但 `MANDATORY_WORKFLOW_TASK`、审批待办及等效强制待办至少必须保留 `IN_APP`，不可退订、不可被聚合丢弃、不可由客户端偏好/静默/免打扰规则关闭。所有偏好变更均要求 CSRF、幂等、乐观锁、当前 IAM 主体校验和审计。
25. **附件接收、隔离与扫描。** 文件名、扩展名、路径、`Content-Type`、客户端 MIME、压缩包目录和 Office 元数据全部不可信，绝不能用于对象键、落盘路径、授权、展示 HTML 或下载响应头。服务端按用途维护允许的实际文件类型/文件签名、单文件大小、解压后大小、压缩层数、每工单数量和总量白名单；使用随机、不可预测对象键写入隔离存储，禁止从请求拼接路径、解压 Zip Slip、符号链接跟随和直接提供对象存储 URL。所有文件均以 `RECEIVED → SCANNING → SCAN_PASSED | QUARANTINED | REJECTED | SCAN_UNAVAILABLE` 状态机处理，扫描通过前不得下载、预览、正文抽取、案例匹配、消息投递、知识导入或发布。扫描服务超时、不可达、回执不完整、签名库过期或状态不确定时必须 fail-closed 为 `SCAN_UNAVAILABLE`/隔离并告警，禁止“先放行后补扫”。
26. **附件下载、展示和保留。** 每次列表、预览、下载和删除申请都应同时执行工单/知识文档关系、对象级权限、当前 IAM 状态、组织/服务范围、文件状态与用途校验；附件 ID、文件名、下载 URL、对象键和历史身份快照均不能替代授权。仅 `SCAN_PASSED` 且未逻辑删除保留的文件可下载；服务端固定 `Content-Disposition: attachment`、使用净化后的展示名、服务端探测 MIME、`X-Content-Type-Options: nosniff`、禁止内联执行，且不返回永久/可猜测的存储地址。文本、CSV、HTML、SVG、PDF 和 Office 文档须防公式注入、XSS/主动内容、宏、外部链接/模板、嵌入对象和预览器沙箱逃逸；对 CSV 进行安全转义，对 Office 宏文档默认拒绝或隔离，对富文本严格净化。删除仅写 `DELETE_REQUESTED/RETAINED` 逻辑状态、授权原因与审计；物理清理仅能由受控保留/法务策略的后台作业执行，不能经普通业务 API、管理员界面或数据库应用账号绕过。
27. **知识库导入、版本与发布审核。** 知识库只支持受控文档导入、服务端文本抽取和人工维护；当前明确不接入 AI、向量检索、自动问答、自动生成、语音建单、自动质检或自动发布。导入任务必须校验当前主体的知识库管理范围、目标组织/服务范围、文件白名单、大小、扫描状态和来源完整性；原始文件先隔离并完成扫描后才能解析，解析器须禁用外部实体、宏执行、远程资源加载、模板执行和任意命令。导入创建不可变草稿版本，正文/标签/分类/关联服务均走字段白名单、净化和审计；不得让客户端提交正文解释器、存储路径、审核人、发布状态、可见范围或覆盖既有版本。文档版本不可原地修改或普通删除；发布、回滚、归档均创建新审计事件和冻结版本。
28. **知识库可见性与发布门禁。** 普通检索与详情仅返回当前主体按组织、服务和文档可见性有权读取的已发布冻结版本；关键词、标签、分页和文档 ID 不得枚举草稿、审核意见、导入任务、其他组织文档、扫描报告、存储路径或原始文件。发布必须执行双人复核/审批与职责分离（申请人不得自审），再次确认版本完整性、正文净化、引用完整性和所有关联文件均 `SCAN_PASSED` 且未逻辑删除；任一文件为隔离、拒绝、扫描未知或扫描服务故障时发布一律阻断。审核、拒绝、发布、归档、删除申请、扫描状态改变、下载和导入失败均记录追加式防篡改审计链，审计中只保存脱敏摘要和状态/原因码，不保存恶意样本、原始文件正文、路径、密钥或完整扫描回执。
29. **SLA 策略、日历与暂停。** SLA 策略、工作日历、目标和暂停条件仅由 `SLA_MANAGER`/受限平台管理员在自身配置管理范围内以草稿—冻结版本—双人复核—发布维护，审计员只读；申请人不得自审，已发布版本绝不原地修改。策略只能使用受控的工单类型/服务/组织/优先级匹配、已发布工作日历版本、业务分钟目标和服务端枚举的暂停/恢复状态，禁止脚本、表达式、任意事件、客户端提供的截止时间/暂停时长、自动升级动作或回写既有工单。发布前服务端必须检测范围越权、无权目录/组织、草稿日历、重叠匹配和优先级歧义；每张工单持久化命中的策略/日历版本快照，所有目标时间、风险、暂停、恢复和违约均基于可信工单事件与该快照计算。当前版本不自动升级、自动转派或自动改变工单状态；配置创建、修改、审核、发布、拒绝、匹配、暂停、恢复和违约均追加审计。
30. **运营报表、汇总与导出。** KPI、趋势、队列负荷、刷新状态和导出查询必须在服务端以当前 IAM 身份、组织/服务/队列数据范围和用途实时过滤，绝不相信客户端组织列表、角色、队列、指标、字段、SQL、排序、聚合、时区、行数、文件名、存储地址或下载链接。跨组织、含下级、超过受控时间跨度/行数阈值的查询，以及所有导出，均要求服务端签发并绑定主体、规范化筛选、用途、报表类型/操作和短时有效期的二次鉴权，逐次审计且不可跨主体/范围/导出任务复用。指标口径、分子分母、状态边界、时区、缺失数据、刷新时刻和汇总延迟必须随响应返回；缺失/滞后数据标记为 `PARTIAL`/`NOT_AVAILABLE`，禁止用零值伪造。报表只可使用固定参数化查询、固定指标白名单、分页/时间范围/复杂度/并发/频率上限与查询超时；禁止动态 SQL、原生表达式、任意列/公式、模板注入、CSV 公式注入和在明细表上无界扫描。高并发统计应使用按范围隔离的受控汇总表/物化聚合、索引和刷新任务，刷新/回补与业务库写入隔离、可限流降级；不暴露表名、SQL、执行计划、节点、缓存键或其他组织数据。导出仅异步生成，下载时再次对象/范围/二次鉴权并审计，强制脱敏/水印、短期保留、`attachment`、净化文件名和 `nosniff`，不返回对象存储地址或永久 URL。

30. **外部集成连接与网络边界。** 外部 CMDB、监控、日志和 APM 只能通过预注册、部署受控的连接器使用；本期不实现自建监控平台、eBPF、自动发现 CMDB 或数据库运维平台。管理员配置只能保存受管密钥服务的逻辑 `secretRef` 和草稿启用意图，绝不接收或回显明文密钥、令牌、私钥、端点、协议、代理、DNS、请求头、回调 URL、租户、脚本或动态连接器类型。连接器允许地址/CIDR、协议、TLS/mTLS、证书校验、DNS 固定策略、出站防火墙、超时、重试上限和固定字段映射均由部署配置强制；禁止管理员、工单字段、标签、模板或请求参数动态决定目标，以消除 SSRF、内网探测和开放代理。配置只能以草稿—冻结—双人复核—发布生效，申请人与审批人职责分离；状态接口仅返回脱敏健康和受管引用可用性，不得泄露端点、连接串、secretRef、供应商 ID、回执、日志或堆栈。
31. **CMDB CI、告警和深链接授权。** CMDB 仅维护已受管来源的只读 CI 投影，禁止借平台写回、自动发现或以 CI ID/名称/分页/关键词枚举越权资源。工单关联 CI 或告警时，服务端同时校验工单关系、当前 IAM 身份、组织/服务/队列数据范围、CI/告警当前可见性、来源连接状态、关联策略、乐观锁和幂等；客户端不能提交 CI 明细、原始告警正文、影响范围、状态、来源连接或审批结论。告警回调只接受已发布连接器的固定入口：验证来源网络、恒定时间签名、签名覆盖的原始载荷、受控时间窗、事件 ID、载荷摘要和持久化去重键；验签失败、时间超窗、重放、未知字段、来源不符或连接禁用一律拒绝并审计，且回调不允许任意 URL、外部写回、自动关闭告警或自动推进工单。日志/APM 深链接只能由服务端按已授权工单及关联 CI/告警、固定受信任基址和路径模板生成短期链接；不得接受/回显客户端 URL、协议、主机、索引、查询、时间范围、token、Cookie、签名或 `redirectUrl`，点击及目标访问仍需完成目标系统认证和对象级授权。
32. **外部数据最小化与审计。** 回调、CMDB/告警投影、深链接请求和连接健康检查仅保存业务必需的脱敏字段；原始日志、APM trace、告警载荷、网络地址、供应商身份、签名、密钥、secretRef、响应正文与堆栈不得写入业务表、普通审计、错误响应、指标标签或前端构建产物。连接草稿/发布、健康变化、回调接收/拒绝/去重、CI/告警查询与关联、深链接生成和访问均记录追加式防篡改审计链，包含请求 ID、可信来源摘要、授权判定、配置/映射版本、对象引用、结果和脱敏原因码；审计员只读，平台管理员和应用数据库账号均不得篡改或删除。

### 3.1 P0 `DATA_SCOPE` 解析门禁

- 授权引擎只接受 `ORGANIZATION` / `SERVICE_SYSTEM` / `SERVICE_CATALOG` / `QUEUE` 等服务端枚举类型及其规范主键，转换为 `DATA_SCOPE_<TYPE>:<ID>` 或等价强类型授权包。未知类型、空值、通配符、名称匹配、客户端范围和旧 `SERVICE` 歧义编码均必须失败关闭；历史编码须经审计迁移，不得兼容放大。
- 角色授权和数据范围必须同时命中；同类型多值取并集，同一授权包的不同类型取交集，多个完整授权包可取并集。实现不得将不同授权包打平后形成组织 × 系统 × 目录 × 队列的扩权笛卡尔积。组织含下级只能使用授权记录中的明确标志与当前 IAM 组织树闭包。
- 工单的组织、服务系统、服务目录和当前队列只能从数据库对象、已发布配置和当前流程状态解析，请求体、路径、搜索索引文档、缓存或历史快照均不得作为当前授权事实。提单人、当前主办/协办、审批候选人等对象关系只授予该关系所需的最小动作，不变成持久全局范围。
- `ROLE_PLATFORM_ADMIN`、`ROLE_AUDITOR`、支持角色和管理菜单均不自动赋予跨组织业务数据。跨组织/全局读取须使用独立的限时授权包、二人复核、用途绑定和逐次审计，不得在代码中为某角色硬编码“读/改全部”。
- 每次请求均重新校验 IAM 启用状态、当前投影版本、后台授权启用状态和授权版本。调岗、停用、角色或范围撤销必须立即失效会话权限、对象授权、列表/搜索/报表缓存和候选集缓存。失去资格的人员不得继续读、下载、处理、审批、导出或接收新业务消息，已在办责任进入受控重分派。

### 3.3 团队成员与审批候选门禁

- 团队/队列成员关系必须是受控、版本化的服务端数据，至少固化队列、IAM ID、职责类型、启用状态、有效期、成员版本、队列授权版本（服务范围/成员政策）、当前 IAM 投影版本和后台授权版本。仅角色、岗位名、队列名或历史处理关系不得推导当前成员资格。
- 候选授权摘要必须绑定 IAM 投影版本、后台授权版本、团队/队列成员版本、队列授权版本、已发布路由/审批政策版本和目标工单范围摘要。IAM 停用/离职/调岗、后台撤权、成员到期/退组、队列授权或政策变更必须主动失效候选、待办和收件人缓存，并使已在办责任进入受控重算/重分派；禁止等待会话过期。
- 审批候选必须在**创建、展示/领取、决策/完成**三阶段分别以服务端目标工单事实复核。创建时冻结合格集；展示时只返回当前仍合格的本人待办；决策时必须同时命中冻结集和当前 IAM/角色/`DATA_SCOPE`/成员/职责分离。任一条件失效均 fail-closed 并告警，不得以任务 ID、冻结快照或历史角色继续。
- 申请人必须从所有审批候选中排除；对分派、转办、交接、授权等直接使某人获益的申请，拟目标人/拟受让人同样排除。排除名单和原因由服务端计算，客户端不得提交、删除或覆盖；任何决策模式均不得自审。
- 候选查询只能从已授权目标工单/任务上下文发起，限制结果数并返回最小字段。不返回全团队/队列名册、候选总数、被排除或无权人员，也不通过分页、排序、空页、错误差异或响应时间泄露存在性。三阶段必须以同一关联 ID 记录各版本、范围/排除摘要、结果和原因码。

### 3.4 知识归属、迁移与 BOLA 门禁

- 知识文档必须有非空的归属组织和已发布服务目录；文档版本、导入任务、审核意见、预览/下载制品、复审任务和反馈必须绑定同一归属快照。归属只能从已发布目录、服务端工单快照或经审批的管理命令得到，不得以创建人、请求人当前组织、标签或路径替代。
- 列表/搜索/详情、草稿/版本/导入队列、审核、发布/归档/复审、预览/下载和反馈必须调用同一强类型授权谓词：当前角色 ∩ `DATA_SCOPE_ORGANIZATION` ∩ `DATA_SCOPE_SERVICE_CATALOG` ∩ 文档/版本/扫描状态。普通人员只读已发布版本，管理/审核角色也不自动全局；审核人不得审核自己创建/导入的草稿或归属变更。
- 详情、版本、导入任务、审核、预览和反馈等子对象 ID 均不是授权。所有入口须先从服务端关系解析父文档归属，再执行同一当前范围校验；分页、总数、标签、建议词、反馈数量和错误响应只能反映授权子集，禁止以状态码、时差或空页枚举其他范围知识。
- 历史数据缺失组织/目录归属，归属已失效/未发布，或无法唯一映射时，所有业务读取、管理、审核、发布、预览和反馈一律 fail-closed，只进入独立迁移待办。迁移不得默认归到创建人组织、全局/首个目录或管理员范围。
- 迁移须先干运行并输出歧义，再经业务责任人与安全/数据责任人双人复核后分批提交。审计必须固化文档 ID、原归属摘要、目标组织/目录、映射规则/脚本版本、申请/复核人、批次、影响行数、失败摘要、事前/事后版本、时间和回退关联，不记录正文或原件。

### 3.5 幂等与队列迁移执行门禁

- 幂等记录的唯一边界必须至少包含：已验证主体、幂等键、受控操作编码、资源类型/资源 ID（新建使用服务端 `NEW` 命名空间）和规范化请求指纹。幂等键不取代当前认证、CSRF、对象授权、状态机和版本前置条件。
- 指纹只由影响业务结果的允许字段、动作、目标和前置版本构成，对 Unicode、时间、数值/枚举、集合顺序、空值和默认值做稳定规范化。同一绑定与指纹只重放首次结果；操作、资源或指纹不同时稳定冲突且不执行。相同键跨主体不得返回他人结果或泄露他人记录存在。
- 记录只保存绑定摘要、不可逆指纹、结果引用/状态、保留期和原因码，不保存原始请求、评论/知识正文、附件内容/文件名、密码/令牌/Cookie、恶意样本或外部回执。低熕敏感值不得单独无盐哈希；使用受控 HMAC/组合指纹。幂等写入与业务、审计/outbox 原子提交。
- 队列迁移计划发起人与审批人必须不同，二者均在当前源/目标队列范围内；计划冻结源/目标队列、队列授权版本、显式任务集/规范化选择规则、计划版本、原因与幂等绑定。禁止申请人自审、浏览器提交“已审批”或绕过计划直接批量修改任务队列。
- 执行开始和逐任务比较更新前，重验执行人当前权限、源/目标队列当前状态/范围/版本、工单当前范围、任务源队列与可迁移状态、目标队列容量和工单/任务版本。每个任务成功/拒绝均记录计划/批次/任务、源/目标队列及版本、事前/事后版本、当前授权摘要、结果与原因码。
- 单任务失败时必须保持原队列/流程/主办不变并明确记录；执行人失权、源/目标队列版本或范围整体失效、计划撤销、数据库/审计写入故障时，立即停止后续任务并以 `BLOCKED`/`FAILED` 关闭。禁止跳过失败、自动放大目标范围、静默创建成员或将部分/未执行记为全部成功。

### 3.6 幂等租约、对账与 HMAC 密钥门禁

- `IN_PROGRESS` 必须持久化租约所有者、到期时间、尝试次数和可比较更新版本。租约未到期只返回处理中/冲突；到期后仅一个节点可用 CAS 接管。心跳只能有界续约，不得使失联记录永不到期。
- 接管前必须以主体/操作/资源/指纹和结果引用对账业务表、审计和 outbox：已成功只补齐幂等结果，证明未执行才重试，不确定则 `RECONCILIATION_REQUIRED`/`FAILED_FINAL` 并告警。不得以租约到期本身证明业务未执行。
- 指纹必须使用 HMAC-SHA-256 或安全团队批准的等价 MAC，每环境密钥至少 32 个随机字节、只从受管密钥系统/部署 secret 注入。每条记录固化 `keyVersion`；新记录只用当前版本，前一版本在受控窗口内只验证旧记录。未知/已撤销版本 fail-closed，不回退无密钥哈希。
- 密钥值、完整 secretRef、环境变量值、MAC 输入/中间值不得出现在源码、测试夹具、配置回显、日志、审计、指标标签、错误响应或线程/崩溃转储。启动时校验密钥长度、当前版本唯一且旧版本只读验证。

### 3.7 V42 历史行分类与启动门禁

- 升级前必须按状态、强结果引用、业务/审计/outbox 证据对 V42 无 `keyVersion`/租约行分类。旧 `IN_PROGRESS` 或证据不确定行进 `RECONCILIATION_REQUIRED`；已成功行仅保留非重签历史证据；确认未执行行最终失败后由原主体使用新键重申请。
- 禁止把 V42 SHA-256 指纹声明为 HMAC，禁止默认回填当前/前一 `keyVersion`。若非空列约束需分类标记，只能使用不在 key ring 中的专用非签发标识，并在代码中明确禁止验证/新签发/重放。
- 人工对账操作人与复核人分离，逐条记录原标识、绑定摘要、原状态、证据摘要、判定、最终状态、批次和时间。不解密/重构原请求，不修改已成功业务/审计事实。
- 生产写流量与工作者启动前，SQL 门禁必须证明全表 `key_version IS NULL` 为0，且旧活动 `IN_PROGRESS` 中缺 `key_version`/`lease_owner`/`lease_expires_at` 的数量为0。任一非零立即阻断，不得靠异常冲突代替数据清理。
- 幂等状态接口只向原主体返回操作/资源摘要、状态、尝试次数、租约到期、安全结果引用与原因码；不返回指纹、幂等键绑定、owner、`keyVersion`、密钥/引用或原始对账证据。

### 3.8 生产附件扫描器门禁

- `prod`/生产等价 profile 必须选择真实、受管扫描器；空实现、固定通过、跳过扫描、仅记录日志或“扫描失败仍可下载”的实现必须在构建或启动时失败。启动检查须验证配置完整、端点命中部署允许列表、网络策略生效、引擎健康和签名库新鲜度；不满足时 readiness 失败并禁止附件入口/工作者接入流量。
- ClamAV 连接仅允许固定 Unix socket、sidecar 或内网允许地址，禁止请求、文件元数据、数据库配置或管理员页面改变主机、端口、协议、DNS、代理或命令。强制连接/写入/读取/总超时、并发/队列、文件/流量和最大响应字节/行数上限；只接受允许的明确终态。超时、断连、截断、畸形/超大响应、未知结果、引擎不可用或签名库过期一律 `SCAN_UNAVAILABLE` 并隔离，不能重试后默认通过。
- 扫描器以独立最小权限服务身份运行，只能处理本次隔离对象或受限字节流；其凭据、证书和版本标识不得复用 IAM、对象存储、消息通道或幂等 HMAC 密钥，不得加入 HMAC key ring、替代 `keyVersion` 或进入业务响应。扫描器网络不得访问互联网、对象存储管理面或非必要内网。
- 恶意命中、扫描不可用、重扫和隔离处置均写追加式审计并告警；审计只含不可逆文件摘要、父对象脱敏引用、扫描器/签名版本、规范化结果/原因码、耗时、主体和关联 ID，不含样本/正文/文件名、原始 ClamAV 回执、路径、端点、凭据或密钥。只有新的明确干净扫描结果才能转为 `SCAN_PASSED`，人工不得直接改状态。

### 3.9 前端草稿、capability 与交互安全门禁

- 浏览器草稿默认内存保存；确需恢复时使用专用草稿仓库，绑定部署/租户、服务端签发的主体命名空间、表单/目录发布版本和临时资源 ID。不得以登录名、显示名、可猜测对象 ID 或单一通用 key 隔离，不得写入密码、令牌、Cookie/CSRF、完整联系方式、内部评论、附件/文件句柄、导出、扫描回执或高密级正文；禁止把普通 `localStorage`、浏览器端加密或混淆视为敏感数据保护。
- 草稿绝对 TTL 不超过 24 小时，固化创建/到期时间且不能由用户活动、本机时间或字段篡改延长。到期、提交、放弃、登出、会话失效、主体切换、调岗撤权和表单版本失配必须立即清除草稿、查询缓存、内存状态和 capability 快照，并通过受控跨标签页通知覆盖同一浏览器会话。恢复时重新校验主体、字段可见性和发布版本，只合并仍有权的非敏感字段，不自动恢复附件或重放写请求。
- capability/allowedActions 仅是服务端计算的短期 UI 提示，缓存绑定主体、资源、授权/对象版本；未知、失败、过期或不匹配时敏感动作默认隐藏/禁用。客户端角色判断、路由、按钮、CSS、快捷键和被篡改 capability 都不得替代后端逐请求对象授权、流程校验、CSRF、幂等与审计。
- dashboard 的未知、部分、滞后、无权、无数据和请求失败必须区分；禁止把非完整数据归零、沿用为当前值或渲染“平稳/无告警/达标”。表单错误仅映射稳定公开码及本次可见字段，不显示原始响应/输入、堆栈、SQL/类名/路径、无权字段/目录/人员或对象存在差异；允许显示脱敏请求 ID。
- 键盘、读屏和移动端必须遵守与鼠标相同的 capability 和后端授权。隐藏动作不进入焦点/可访问树；全局快捷键在输入、输入法组合和弹窗内失效，危险动作需明确确认并防 Enter/触摸连击重复提交。移动布局在横竖屏、缩放、软键盘和返回导航下不得重叠主次动作、恢复他主体缓存或把敏感内容放入 URL、系统分享、剪贴板、通知预览及前端埋点。

## 4. 自动化质量门禁

| 阶段 | 必须执行 | 阻断条件 |
|---|---|---|
| 提交前 | 格式化、单元测试、secret 扫描、依赖/锁文件变化检查。 | 密钥命中、测试失败、未锁定依赖。 |
| 合并请求 | 后端编译与单测、前端类型检查与构建、OpenAPI 校验与前后端契约测试、SAST、SCA、许可证扫描。 | 严重/高危 CVE、SAST 高危、契约破坏或测试失败。 |
| 集成环境 | 鉴权矩阵测试、IDOR/BOLA 负测、CSRF/CORS、XSS、上传下载、限流、幂等、审计防篡改/完整性和关键流程/协同动作回归。 | 任一 P0 安全用例失败。 |
| 发布前 | 镜像扫描、SBOM 签名/归档、部署配置基线检查、数据库迁移回滚演练、漏洞例外复核。 | 未扫描制品、例外过期、配置含密钥或无回滚。 |

### 最小授权测试矩阵

- 前端草稿测试必须在同一浏览器 profile 中覆盖用户 A→登出→用户 B、跨租户/组织、两标签页、刷新/崩溃恢复、TTL 到期、本机时间篡改、调岗撤权和表单发布更版：B 及失权后的 A 均看不到旧草稿/查询缓存/capability，所有标签页同步清理，过期时间不能滑动延长，恢复内容不含凭据、完整个人信息、内部评论、附件/文件句柄、导出或高密级正文，提交/放弃后无残留且不自动重放。
- capability 测试必须篡改浏览器 store、缓存、路由、DOM/CSS、disabled 属性和 API 返回，使无权按钮出现并直接调用接口；后端仍按当前主体/对象/授权版本拒绝且不泄露存在性。还须覆盖 capability 超时/失败/旧主体缓存、授权版本变化和多标签页切换，断言未知时敏感动作关闭而合法基本浏览可降级提示。
- dashboard 与表单防泄露测试必须注入 `UNKNOWN`/`PARTIAL`/`STALE`、超时、无权、空数据、最后成功值和跨主体旧缓存，断言不出现零值伪造、绿色“平稳/无告警/达标”或无权分组/趋势/时间差。逐一伪造隐藏字段、无权目录/人员/对象 ID、后端堆栈和恶意输入，错误界面只能显示稳定防枚举文案、当前可见字段和脱敏请求 ID，URL、日志、埋点与通知不含原始响应/输入。
- 键盘、读屏与移动端测试必须覆盖 Tab/Shift+Tab、Enter/Space/Escape、输入法组合、按键长按/连击、焦点陷阱、屏幕阅读器可访问树、软键盘、横竖屏、200% 缩放、返回/前进、触摸双击和窄屏主次按钮。隐藏/无权动作不可聚焦或朗读，快捷键不在输入/弹窗中触发敏感动作，危险动作须确认且幂等，布局不得重叠造成误触，用户切换后返回导航不得显示旧主体内容，敏感数据不得进入 URL、分享、剪贴板或通知预览。
- 提单人只能访问自己提交或被授权订阅的工单；变造路径中的工单编号、请求人、组织或附件 ID 必须被拒绝或按防枚举策略返回 404。
- 一线、二线、审批人、服务经理、平台管理员、审计员分别覆盖允许与拒绝用例；平台管理员不能篡改审计记录，审计员不能执行流程动作。
- `DATA_SCOPE` 组合测试必须覆盖：同组织不同系统、同系统不同目录、同目录不同队列、同类型多值并集、不同类型交集、多授权包并集、跨包打平笛卡尔积、组织含下级、未知/旧歧义类型和通配符。平台管理员、审计员和支持角色在无明确授权包时均不得读取或变更对象。
- 集合接口测试必须在混合有权/无权数据与大数据量下断言：SQL/索引先按范围过滤再排序分页，总数、空页、搜索建议、分组/KPI 和导出行数只反映授权子集；cursor、缓存、索引分区和导出文件不能跨主体/范围复用，授权版本变更后立即失效。
- 候选路由测试必须覆盖跨组织/系统/目录/队列候选人，无权候选人搜索和总数枚举，任务创建后调岗/停用/撤权，过期候选缓存，以及无候选人时的队列留置与告警。任务创建、展示、抢单/分派、交接确认和审批决策均须有重新计算及可关联审计证据。
- 团队/队列成员版本测试必须覆盖：角色有效但未入队、成员关系到期/停用/退组、成员版本与待办投影不一致、IAM 停用/调岗、后台范围撤销、路由政策更版和缓存未及时失效。上述变更后下一次请求必须禁止展示、领取、完成和新通知，已在办责任进入重算/重分派并产生审计告警。

- 每个写操作测试：失效会话、缺失/错误 CSRF、越权对象、过期/错误流程任务、过期乐观锁版本、重复幂等键以及并发提交。所有工单生命周期动作、转办/协办/抢单/主办协办/交接班和内部评论均须覆盖；请求体伪造状态、优先级、队列、处理人、流程变量、审批结论、SLA 时间、用户/组织/角色时必须被拒绝或服务端忽略并留痕。

- HMAC 测试必须覆盖缺密钥、少于32字节、未知/已撤销 `keyVersion`、新旧版本并存、切换新签发、旧记录验证和清窗撤销。扫描构建产物、环境展开、配置端点、日志/审计/指标/错误/崩溃转储，断言无密钥、完整引用或 HMAC 中间值。
- V42 历史行测试必须构造无 `keyVersion` 的 `IN_PROGRESS`/`SUCCEEDED`/失败行、有无强结果引用和业务/审计/outbox 一致/冲突组合；验证分类不伪造当前 `keyVersion`、旧 `IN_PROGRESS` 不被自动接管/重做、人工对账双人复核与逐条审计。启动前执行与生产相同 SQL，断言零 `key_version IS NULL`、零缺租约的旧活动 `IN_PROGRESS`；状态接口不返回指纹、owner、`keyVersion`或原始证据。
- 队列迁移计划测试必须覆盖申请人自审、审批人无源/目标范围、审批后执行人撤权、源/目标队列停用/更版/改范围、任务离开源队列/已完成、目标超容、工单/任务版本竞争、重复幂等键和中途数据库/审计失败。断言每任务成功/拒绝均有唯一审计，失败任务原队列/流程/主办不变，系统性失效停止后续执行并以 `BLOCKED`/`FAILED` 关闭，不得静默跳过或伪造全部成功。
- 受控跳转测试必须覆盖：伪造来源任务、跨工单任务、未在白名单的目标节点、试图跨越硬审批/授权节点、缺少双人审批、错误任务处置与 SLA 影响篡改；均不得执行跳转。成功申请、审批、执行与拒绝各自生成可校验且不可修改的审计链事件。
- 审计完整性测试必须验证：所有成功或拒绝的写动作均有唯一关联审计事件与身份快照；审计员、平台管理员和数据库应用账号不能经业务 API 更新/删除历史审计；篡改链、缺失事件、事件顺序错误均触发告警并阻断发布。
- 导出、批量查询、跨组织查看和附件下载必须二次授权，验证用途、范围、水印与审计事件。
- IAM 投影测试必须覆盖：停用/离职用户不能登录、不能成为新任务候选人或消息收件人；调岗后新工单按新数据范围授权、既有事件身份快照不变；伪造 IAM 用户 ID、组织 ID、岗位、角色、投影版本或候选人场景均不能提升权限或改变分派结果。
- IAM 同步测试必须覆盖：无管理员/运维职责触发被拒绝；并发全量/增量请求只会受控排队或幂等合并；未知来源、过大/损坏/重复/组织环路导入、字段外写入、携带脚本或密钥的请求均被拒绝并审计；同步状态接口不泄露连接串、令牌、原始载荷、完整失败行或无权组织/用户。

- 动态表单测试必须覆盖：伪造/未知字段、删除必填字段、向隐藏或无权字段写值、错配字段类型、超长值、非法枚举/字典值、越权联动参数、篡改目录或表单版本、过期缓存和请求夹带状态/人员/队列/优先级/流程变量；均应由服务端拒绝，且错误信息不得泄露无权字段或目录。
- 字典和标签测试必须覆盖：跨组织/服务读取与维护、重复/复用编码、层级环、已引用条目静默删除/变义、草稿值提前可用、Unicode 同形/规范化绕过、HTML/脚本/控制字符标签、超数量/超长度标签以及通过标签影响路由或数据范围；必须拒绝并产生可关联审计。
- 目录发布测试必须覆盖：无角色或无管理范围写入、越权读取草稿、跳过复核、申请人自审、发布版本原地修改、乐观锁竞争、引用未发布字典/标签、未审计回滚及缓存使用草稿；生产运行中的建单和匹配只允许最后有效发布版本。

- 知识归属与 BOLA 测试必须用相同样本矩阵覆盖列表/搜索/详情、草稿/版本/导入任务/审核意见、发布/归档/复审、预览/下载和反馈/反馈汇总：只改变文档 ID、版本 ID、任务 ID、审核 ID、反馈 ID、分页/关键词/标签或错误路径均不得越过“当前角色 ∩ 归属组织 ∩ 服务目录 ∩ 文档/版本/扫描状态”。普通人员只能读/反馈当前可见的已发布版本，管理/审核角色也必须同时命中组织和目录范围，审核人不得自审。
- 知识历史迁移测试必须覆盖组织/目录任一为空、已停用、未发布、多义映射和部分批次失败；未完成唯一归属的记录必须从业务列表、管理/审核队列、预览、发布和反馈中全部 fail-closed。验证干运行不写库，双人复核、分批幂等、事前/事后版本、失败行摘要、回退批次和不可篡改审计完整；禁止默认归属创建人、全局/首个目录或管理员。
- SLA 配置与计算测试必须覆盖：无 `SLA_MANAGER`/越配置范围读取或创建，策略/日历 ID 枚举，客户端伪造版本、发布状态、审核人、组织/服务范围、优先级、工作日历、截止时间、暂停时长、暂停条件、自动升级或工单状态；已发布版本原地修改、申请人自审、草稿日历被引用、未发布策略生效、重叠匹配/优先级歧义、调岗后越权维护、并发版本创建/发布和重复幂等键。还必须验证可信事件驱动的暂停/恢复、工作日历时区/DST 边界、节假日、风险/违约计算、策略和日历快照不可因后续配置修改而变化，以及当前版本绝不自动升级、转派或推进工单状态；成功/拒绝/计算均有唯一追加审计关联。
- 运营报表与导出测试必须覆盖：普通主体、审计员、服务经理、平台管理员对 KPI、趋势、队列负荷、刷新状态、导出任务和下载的允许/拒绝矩阵；篡改组织/队列/服务范围、含下级、时间跨度、时区、指标、粒度、用途、二次鉴权授权凭据、导出任务 ID、格式、行数、字段、文件名、下载 URL 或重复幂等键。跨组织、大范围和所有导出均须无例外触发二次鉴权且绑定主体/规范化筛选/用途/操作/短期有效期，下载时再次校验并审计。测试注入动态 SQL、排序/聚合表达式、公式/模板、CSV 公式、Unicode 绕过及报表参数耗尽；验证固定参数化查询、限流/并发/超时、索引与按范围隔离的汇总表、汇总刷新滞后/缺失分区不被显示为零、业务写入不被报表扫描阻塞、导出为 attachment+nosniff+水印/脱敏+短期保留且不泄露对象存储 URL、SQL/执行计划/作业节点或其他组织数据。

- 外部连接配置测试必须覆盖：无 `INTEGRATION_ADMIN`/越管理范围读取或改动、枚举连接编码、客户端提交明文密钥/令牌/私钥/端点/协议/代理/DNS/请求头/回调 URL/租户/脚本/连接器类型、secretRef 路径回显、草稿立即生效、申请人自审、审计员写入、并发版本覆盖、失效/不存在 secretRef、未受信任 CA、非允许地址和 DNS 重绑定。测试必须断言所有连接状态、错误、日志、指标、OpenAPI 示例和审计详情均不含端点、连接串、secretRef、供应商 ID、密钥、签名或原始回执，且没有自建监控、eBPF、自动发现 CMDB、数据库运维平台能力被意外调用。
- 外部告警回调测试必须覆盖：错误/缺失签名、错误来源网络、签名不覆盖原始体、篡改 body/时间戳/事件 ID、时间窗外、重复事件、同事件跨连接、乱序重试、未知字段、禁用/未发布连接、超频、持久化失败后的重试和服务重启；任何失败均不得创建/更新告警、CI 关联、工单、流程或消息，成功与重复抑制均有唯一审计。回调接口不得接受 Cookie 会话替代签名、客户端指定的目标 URL、内部网络地址、写回动作或任意供应商载荷。
- CMDB、告警关联和日志/APM 深链接测试必须覆盖：篡改 CI/告警/工单 ID、分页、关键词、组织/服务范围、关联版本、关联理由、来源连接、告警状态或影响等级，跨组织/调岗/停用主体、平台管理员/审计员越权及并发重复关联；均按防枚举策略拒绝且不泄露对象。深链接必须拒绝非受信任基址、外部协议、路径穿越、`returnUrl`/`redirectUrl`、用户提供的查询/索引/主机/时间范围、token/Cookie/签名和越权资源；生成与点击后均重新授权并审计，且日志/APM 原始数据、trace、索引、网络地址和凭据不得透出。

## 5. 安全例外

例外记录至少含：组件/漏洞或控制项、受影响版本与资产、CVSS/业务影响、补偿控制、责任人、批准人、创建/到期时间、修复版本和复测证据。例外不得用于绕过对象级鉴权、密钥扫描或严重/高危漏洞的长期修复责任。
