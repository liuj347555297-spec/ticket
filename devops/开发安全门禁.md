# 开发安全门禁

适用范围：Vue 3 前端、Spring Boot 单体、Flowable、构建镜像与所有交付脚本。门禁应在内网 CI 中运行；任何例外必须由安全负责人书面批准、标注责任人和失效日期。

## 1. 版本与供应链

| 控制项 | 强制要求 | 发布判定 |
|---|---|---|
| 版本冻结 | Maven 使用 parent/BOM 与 Maven Wrapper；前端使用 `package-lock.json` 或 `pnpm-lock.yaml` 并执行 lockfile-only 安装；容器镜像使用不可变 digest。 | 锁文件、Wrapper 或镜像 digest 缺失即失败。 |
| 依赖来源 | Maven/npm 只允许访问内网制品库；依赖代理、来源和校验和可追溯。禁止构建时从公网临时下载。 | 发现未授权仓库或动态版本（`LATEST`、`RELEASE`、范围版本）即失败。 |
| SBOM | 每次构建生成 CycloneDX 或 SPDX SBOM，覆盖 Maven、npm、容器/基础镜像与操作系统包；与制品、构建号、Git 提交关联保存。 | 没有 SBOM 不得进入制品库。 |
| CVE / 许可证 | 扫描直接与传递依赖、镜像和 OS 包；严重/高危漏洞默认阻断，中危须风险例外，低危纳入修复计划。仅使用通过法务许可清单的许可证。 | 严重/高危未豁免即失败；豁免到期自动恢复阻断。 |
| 补丁治理 | 升级经测试、SBOM 重生成与 CVE 复扫；离线补丁须记录来源、哈希、审批、影响和回滚方案。 | 无变更记录或复扫结果不得发布。 |

## 2. 密钥、配置与构建

- 代码、测试夹具、构建日志、前端打包产物不得含密码、访问令牌、私钥、Cookie、真实个人信息或生产连接串；提交、合并请求和发布前均执行 secret 扫描。
- 密钥只从受管密钥服务或部署环境注入，采用最小权限和可轮换标识；禁止将 `.env`、证书私钥或明文 `application-prod.yml` 提交 Git。
- CI 采用最小权限短期凭据，构建环境隔离；构建脚本不得以管理员/root 身份运行，不执行未经固定版本约束的远程脚本。
- 产物必须可复现并带构建号、Git commit、SBOM 和签名/哈希；部署只接收来自受信任制品库的已扫描产物。

## 3. 越权与接口安全（必须由后端执行）

1. **默认拒绝。** 每个业务接口、服务方法和异步消费者同时校验：当前身份状态、RBAC、组织/服务/队列/CI 数据范围、工单关系以及当前状态/流程任务。
2. **对象级授权。** 工单详情、列表、评论、附件、导出、审批、告警关联、知识正文和报表均逐对象验证；不得只依赖菜单、按钮、前端路由或列表过滤。禁止相信请求中的用户 ID、组织 ID、角色、队列、优先级、状态或处理人。
3. **流程与协同动作。** Flowable 任务 ID、流程节点编码、目标 IAM 用户 ID 均不代表授权。提交、分类、分派、受理、处理中、待反馈、解决、关闭、重开、撤销、挂起、恢复、升级、转办、协办、抢单、主办指定、交接班、会签、内部评论必须逐次校验：对象关系、角色/数据范围、当前状态、流程实例归属、已发布 BPMN 定义版本/节点、任务候选人/受让人/委派关系、工单与任务双乐观锁版本、动作字段白名单和审批策略。目标状态、流程变量、审批结论、SLA 时间、优先级、队列、处理人、候选人名单、会签阈值和授权范围不得信任客户端传入值。
4. **候选人、抢单与会签。** 候选资格由已发布 BPMN/服务目录规则和当前 IAM 投影实时计算，不能通过用户搜索结果、任务 ID、缓存或客户端传入的候选人 ID 获得。抢单须以任务受让条件和双版本原子比较更新，成功者唯一；释放、委派、转办和交接班须验证班次、技能、队列、数据范围、职责分离和当前处理关系。会签使用服务端控制的 BPMN 多实例/会签策略，参与人数、通过阈值、完成条件及未完成任务处置不可由请求体修改；参与人增减、会签完成和超时均记录独立审计事件。
5. **受控跳转。** 只能创建审批申请，不能通过 API 直接移动流程实例；服务端验证来源任务归属、节点白名单、硬审批/授权节点保护、双人审批、任务处置和 SLA 影响。申请、审批、执行、拒绝均产生不可篡改审计事件，且审计员与平台管理员均不得修改或删除。
6. **防重放与幂等。** 每个工单、任务、协同、评论和跳转写操作必须同时验证会话 CSRF、一次业务意图的 `Idempotency-Key`、认证主体、操作类型、目标工单/任务及规范化请求指纹；相同绑定仅返回第一次结果，键复用但内容/主体/目标不一致必须冲突。幂等记录在保留期内防重放、在过期后按受控策略拒绝或重新申请，且与流程/审计事务原子关联；禁止只按 UUID 或仅在前端去重。
7. **会话。** 使用 OIDC 授权码 + PKCE（启用 SSO 时）和服务端 `HttpOnly`、`Secure`、`SameSite` Cookie；访问令牌不得放在 localStorage。所有写接口验证 CSRF 令牌，CORS 仅允许明确的内网门户源站。
8. **输入与输出。** 使用 Bean Validation、允许列表、参数化查询、分页上限和统一错误模型；富文本服务端净化并配置 CSP，禁止内联脚本。文件隔离存储、随机对象键、扫描后放行、下载再次对象鉴权。
9. **审计。** 对登录、授权拒绝、配置、导出、附件下载、流程和集成调用记录请求 ID、主体、对象、结果、来源和前后摘要；日志不得记录密码、令牌、Cookie、完整敏感附件或堆栈。审计事件须使用追加写、时间戳、事件序号/关联 ID、前序哈希或等效防篡改链，并将操作时的 IAM 身份快照与授权判定摘要一并固化；业务事务提交失败不得留下伪成功审计，成功动作不得缺失审计。
10. **IAM 只读投影与同步。** 平台仅保存 IAM 用户、组织、岗位及其映射角色/数据范围的只读投影：不保存密码、不创建本地认证账号、不通过平台编辑或停用 IAM 用户/组织。同步只允许使用受管连接器、固定字段映射和服务端保存的增量游标；触发请求、导入文件或消息不得携带 IAM 地址、密钥、令牌、任意脚本或未验证的字段映射。全量同步须受维护窗口、频率、容量和单飞/幂等锁控制；增量/全量任务均记录申请人身份快照、来源版本摘要、记录计数、结果、拒绝原因码和不可篡改审计关联。
11. **同步导入与个人信息最小化。** 若 IAM 采用文件或批量导入作为受控备选，仅接受管理员预登记的来源、格式、签名/校验和、大小和字段白名单；先在隔离区做结构、编码、重复 ID、组织环路和越权字段校验，再由服务端事务化合并。原始文件、失败行和完整联系方式不得通过 API、应用日志、工单评论或普通审计详情返回；按数据保留期加密留存或安全清理。用户/组织查询按数据范围、用途和最小字段集返回，并限流、防枚举。
12. **历史身份一致性。** 工单提交、分派、审批、协作、评论、消息和审计事件保存 IAM 用户 ID 与当时的姓名、组织、岗位、角色摘要、投影版本和时间快照。调岗、改名、停用或组织重组不得回写历史快照；当前 IAM 投影仅用于新的授权与候选人计算。
13. **服务目录与动态表单。** 运行时只允许读取当前主体可见的已发布目录/表单版本；创建工单、预匹配和字典联动均由服务端按该版本重新校验。动态 `structuredFields` 只可包含已发布字段编码，未知、隐藏、只读、类型不符、无效字典值、无效联动值以及超限字段必须拒绝，不得“兼容保留”。字段定义仅支持受控字段类型、长度/范围、内置格式规则和声明式条件；禁止 HTML、JavaScript、模板表达式、正则注入、SQL、任意 URL/回调、动态组件、任意流程变量和前端规则代码。敏感字段默认不参与案例匹配，接口/日志/错误信息按字段脱敏策略最小化返回。
14. **字典与标签治理。** 字典和标准标签的维护按服务/组织数据范围逐对象授权、乐观锁、审批发布和不可篡改审计；已被发布表单或历史工单引用的编码不得静默删除、复用或改变语义。字典条目必须校验唯一编码、层级环、适用范围、大小和发布状态；运行时仅返回字段声明且当前主体有权使用的有效值。标签统一 Unicode 规范化、去重、长度/数量限制、保留词和控制字符检查，按纯文本输出编码；禁止以标签、字典名称、说明或帮助文本注入 HTML/XSS、链接、脚本、路由、权限或数据范围。自由标签只能作为受限业务检索输入，不能创建标准标签或影响自动路由。
15. **目录管理与发布。** 目录、动态表单、字典、标准标签和规则均先生成草稿，发布必须冻结版本、校验引用完整性、走双人复核/审批（申请人与审批人不得为同一主体）并记录身份快照、变更前后摘要、数据范围、审批与审计关联。平台管理员不因角色自动跨越业务管理范围；审计员只读且不能写配置。发布版本不可原地修改，回滚只能选择已审计的历史发布版本并再次审批；运行中请求不得使用草稿或未审批缓存。
16. **规则案例匹配。** 建单前匹配仅使用已发布、版本受控的确定性规则：目录、CI、允许的结构化字段、标准标签、错误码和规范化关键词。当前禁止 AI、向量检索、语音、外部模型调用、自动处置、自动建单、自动关闭和客户端提交/修改规则表达式、分数、案例可见性或路由结果。规则输入先按动态表单和数据范围校验、限流、脱敏；规则输出仅可返回当前主体有权查看的脱敏知识/已解决案例摘要，不得泄露工单、内部评论、附件、处理人、规则实现、其他组织服务或敏感字段。规则配置来源、版本、命中与建议展示必须审计，且规则变更与业务配置一样受控发布。

## 4. 自动化质量门禁

| 阶段 | 必须执行 | 阻断条件 |
|---|---|---|
| 提交前 | 格式化、单元测试、secret 扫描、依赖/锁文件变化检查。 | 密钥命中、测试失败、未锁定依赖。 |
| 合并请求 | 后端编译与单测、前端类型检查与构建、OpenAPI 校验与前后端契约测试、SAST、SCA、许可证扫描。 | 严重/高危 CVE、SAST 高危、契约破坏或测试失败。 |
| 集成环境 | 鉴权矩阵测试、IDOR/BOLA 负测、CSRF/CORS、XSS、上传下载、限流、幂等、审计防篡改/完整性和关键流程/协同动作回归。 | 任一 P0 安全用例失败。 |
| 发布前 | 镜像扫描、SBOM 签名/归档、部署配置基线检查、数据库迁移回滚演练、漏洞例外复核。 | 未扫描制品、例外过期、配置含密钥或无回滚。 |

### 最小授权测试矩阵

- 提单人只能访问自己提交或被授权订阅的工单；变造路径中的工单编号、请求人、组织或附件 ID 必须被拒绝或按防枚举策略返回 404。
- 一线、二线、审批人、服务经理、平台管理员、审计员分别覆盖允许与拒绝用例；平台管理员不能篡改审计记录，审计员不能执行流程动作。
- 每个写操作测试：失效会话、缺失/错误 CSRF、越权对象、过期/错误流程任务、过期乐观锁版本、重复幂等键以及并发提交。所有工单生命周期动作、转办/协办/抢单/主办协办/交接班和内部评论均须覆盖；请求体伪造状态、优先级、队列、处理人、流程变量、审批结论、SLA 时间、用户/组织/角色时必须被拒绝或服务端忽略并留痕。
- 为每个允许与拒绝的流程动作运行状态机测试：验证仅允许发布流程定义中的合法迁移；分类/分派/受理/关闭/重开/撤销/挂起/升级等被配置为审批时，动作只能产生待审批任务，未审批不得变更最终状态或受让人。
- 并发测试必须覆盖两人抢单、同版本转办/关闭竞争和重复交接班：恰有一个请求成功，其他请求返回 `VERSION_CONFLICT` 或等价安全冲突，且不存在重复受让、丢失处理人或重复审计。
- BPMN 任务测试必须覆盖：伪造/跨工单/已结束/已迁移任务 ID，过期流程定义版本或节点，候选人冒充受让人，受让人冒充候选人，委派人越权完成，被撤销/停用/调岗人员继续操作及通过任务列表枚举其他队列候选人；均不得推进流程或泄露对象存在性。每次任务动作必须同时校验工单 `version` 与 `taskVersion`。
- 会签测试必须覆盖：客户端伪造参与人、会签阈值、完成计数、通过策略或他人意见；同一会签人重复完成；多个会签人并发完成；参与人移除与完成竞争；会签未达阈值提前推进以及发起人自审。服务端只能根据已发布 BPMN 多实例策略决定结束，事件顺序、身份快照和会签进度必须可追溯。
- 防重放测试必须覆盖：同一主体、接口、工单/任务、请求指纹和幂等键重试只返回第一次结果且不重复创建任务/评论/审计；相同键跨主体、跨工单/任务、跨操作或修改理由/结构化字段必须返回 `IDEMPOTENCY_CONFLICT`；过期键、并发相同键和网络超时重试不得产生重复抢单、转办、会签、跳转申请或状态迁移。
- 受控跳转测试必须覆盖：伪造来源任务、跨工单任务、未在白名单的目标节点、试图跨越硬审批/授权节点、缺少双人审批、错误任务处置与 SLA 影响篡改；均不得执行跳转。成功申请、审批、执行与拒绝各自生成可校验且不可修改的审计链事件。
- 审计完整性测试必须验证：所有成功或拒绝的写动作均有唯一关联审计事件与身份快照；审计员、平台管理员和数据库应用账号不能经业务 API 更新/删除历史审计；篡改链、缺失事件、事件顺序错误均触发告警并阻断发布。
- 导出、批量查询、跨组织查看和附件下载必须二次授权，验证用途、范围、水印与审计事件。
- IAM 投影测试必须覆盖：停用/离职用户不能登录、不能成为新任务候选人或消息收件人；调岗后新工单按新数据范围授权、既有事件身份快照不变；伪造 IAM 用户 ID、组织 ID、岗位、角色、投影版本或候选人场景均不能提升权限或改变分派结果。
- IAM 同步测试必须覆盖：无管理员/运维职责触发被拒绝；并发全量/增量请求只会受控排队或幂等合并；未知来源、过大/损坏/重复/组织环路导入、字段外写入、携带脚本或密钥的请求均被拒绝并审计；同步状态接口不泄露连接串、令牌、原始载荷、完整失败行或无权组织/用户。
- 脱敏与审计测试必须覆盖：用户/组织搜索不能通过分页、模糊关键词或停用标志枚举越权对象；日志、错误响应、导出和同步摘要不含密码、令牌、Cookie、完整联系方式或原始 IAM 载荷；每次同步申请、开始、成功、部分成功、失败和拒绝均有唯一身份快照、来源版本摘要和防篡改审计关联。
- 动态表单测试必须覆盖：伪造/未知字段、删除必填字段、向隐藏或无权字段写值、错配字段类型、超长值、非法枚举/字典值、越权联动参数、篡改目录或表单版本、过期缓存和请求夹带状态/人员/队列/优先级/流程变量；均应由服务端拒绝，且错误信息不得泄露无权字段或目录。
- 字典和标签测试必须覆盖：跨组织/服务读取与维护、重复/复用编码、层级环、已引用条目静默删除/变义、草稿值提前可用、Unicode 同形/规范化绕过、HTML/脚本/控制字符标签、超数量/超长度标签以及通过标签影响路由或数据范围；必须拒绝并产生可关联审计。
- 目录发布测试必须覆盖：无角色或无管理范围写入、越权读取草稿、跳过复核、申请人自审、发布版本原地修改、乐观锁竞争、引用未发布字典/标签、未审计回滚及缓存使用草稿；生产运行中的建单和匹配只允许最后有效发布版本。
- 规则案例匹配测试必须覆盖：客户端伪造规则 ID/分数/案例 ID/可见性、敏感字段参与匹配、无权案例或知识泄露、关键词/标签注入、跨组织 CI 匹配、规则投毒（脚本、表达式、任意外部 URL）、规则版本未发布即生效和自动处置；响应只能包含当前主体可见的脱敏建议，且不调用 AI、向量或外部服务。

## 5. 安全例外

例外记录至少含：组件/漏洞或控制项、受影响版本与资产、CVSS/业务影响、补偿控制、责任人、批准人、创建/到期时间、修复版本和复测证据。例外不得用于绕过对象级鉴权、密钥扫描或严重/高危漏洞的长期修复责任。
